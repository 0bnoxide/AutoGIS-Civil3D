### Required source fix

The archived 0.1.1 kit does not compile against real Autodesk
assemblies: `catch (Exception)` in `DiagnosticsCommands.cs` is ambiguous
between `System.Exception` and `Autodesk.AutoCAD.Runtime.Exception`
(CS0104). Fixed in-tree by qualifying it as `System.Exception`. Any
build from the archived `0.1.1` ZIP will fail until it carries this fix.
