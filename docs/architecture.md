# Repository architecture

The repository-level dependency and module map. The LandXML contract seam —
producer rules, package shape, validator behavior, and the future adapter —
is detailed in [docs/architecture-handoff.md](architecture-handoff.md) and
not duplicated here.

## Modules

| Path | What it is | Depends on |
|---|---|---|
| `contract/v1/` | The language-neutral handoff contract: JSON Schema and normative README | nothing |
| `src/AutoGIS.Civil3D.Handoff/` | Pure .NET 8 validator library | contract only — no Autodesk, no ArcGIS |
| `src/AutoGIS.Civil3D.Handoff.Cli/` | Thin console mapping reports to text and stable exit codes | the validator library |
| `tests/AutoGIS.Civil3D.Handoff.Tests/` | xUnit suite and golden fixture regeneration checks | the two above |
| `tools/AutoGIS.Civil3D.FixtureBuilder/` | Non-shipping fixture generator | validator internals |
| `fixtures/v1/` | Golden package corpus (valid and invalid) | generated by the fixture builder |
| `diagnostics/`, `artifacts/diagnostics/` | Preserved diagnostic evidence and its buildable source | standalone; never modified as a side effect |
| `tools/agent-coordination/` | Agent coordination: main protection, claims, ADR allocation (Python, stdlib) | git only; outside the product graph |
| `tools/checks/` | Blocking documentation checks (Python, stdlib) | git only |
| `tools/agent-assets/` | Canonical skills and agent definitions plus the deterministic sync | nothing |
| `tools/agent-hooks/` | Session-start hooks shared by both harnesses | codebase-memory (optional) |
| `.githooks/`, `.claude/`, `.codex/`, `.agents/` | Thin adapters and rendered assets over the tools above | the tools above |

## Dependency rules

- Product code (`contract/`, `src/`, `tests/`) never references Autodesk,
  ArcGIS, or any agent tooling. The dependency direction of the contract
  seam is recorded in [ADR-0001](adr/0001-handoff-contract-ownership.md).
- Agent and repository tooling (`tools/`, hooks, harness directories) never
  enters the product dependency graph or the shipped Civil 3D bundle
  ([ADR-0002](adr/0002-agent-collaboration-and-main-protection.md)).
- A future Autodesk adapter depends on the validator, never the reverse.

Phase sequence and gate state: [docs/roadmap.md](roadmap.md). Operating
policy: [docs/agent-guide.md](agent-guide.md).
